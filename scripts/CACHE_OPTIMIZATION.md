# RSS 缓存系统优化说明

## 📋 更新内容

### 新的缓存结构

**旧格式**（列表）：
```json
{
  "processed_urls": [
    "https://example.com/article1",
    "https://example.com/article2",
    ...
  ],
  "last_run": "2026-08-24T08:00:00"
}
```

**新格式**（按日期组织）：
```json
{
  "by_date": {
    "2026-08-20": [
      "https://example.com/article1",
      "https://example.com/article2"
    ],
    "2026-08-21": [
      "https://example.com/article3"
    ]
  },
  "last_run": "2026-08-24T08:00:00",
  "version": "2.0"
}
```

### 优势

1. **按天管理**：每天的文章 URL 独立存储，便于追溯
2. **自动清理**：可以清理超过 N 天的旧缓存，防止文件过大
3. **精确统计**：可以查看每天处理了多少文章
4. **向后兼容**：自动迁移旧格式到新格式

## 🔧 新增功能

### 1. 自动缓存迁移

脚本运行时会自动检测并迁移旧格式：

```
🔄 检测到旧缓存格式，正在迁移...
✅ 已迁移 765 个 URL 到 2026-08-23
```

### 2. 自动清理旧缓存

每次保存报告时，自动清理超过 30 天的缓存：

```python
# 在 save_report() 中
self._cleanup_old_cache(keep_days=30)
```

输出示例：
```
🧹 清理了 5 天的旧缓存（1250 个 URL）
   保留范围: 2026-07-25 至今
```

### 3. 详细的缓存统计

保存报告时显示详细信息：

```
✅ 缓存已更新:
   • 今日新增: 25 个 URL
   • 总计: 765 个 URL，跨 1 天
   • 缓存日期范围: 2026-08-23 至 2026-08-23
```

```bash
python3 scripts/cache_manager.py details 2026-08-23
```

### 清理旧缓存

```bash
# 交互式清理（需要确认）
python3 scripts/cache_manager.py cleanup --days 30

# 直接清理，跳过确认
python3 scripts/cache_manager.py cleanup --days 30 --yes
```

输出：
```
============================================================

============================================================

保留范围: 2026-07-25 至今

✅ 缓存已更新
```

### 删除指定日期的缓存

```bash
# 交互式删除（需要确认）
python3 scripts/cache_manager.py remove 2026-08-20

# 直接删除，跳过确认
python3 scripts/cache_manager.py remove 2026-08-20 --yes
```

## 🔍 代码变更

### 主要修改的方法

1. **`_load_cache()`**：支持加载新格式，自动迁移旧格式
2. **`_save_cache()`**：保存为新格式
3. **`_cleanup_old_cache()`**：新增，清理旧缓存
4. **`_get_all_cached_urls()`**：新增，获取所有缓存的 URL
5. **`_is_duplicate()`**：使用新的查询方法
6. **`save_report()`**：按日期保存 URL，调用自动清理

### 兼容性

- ✅ 向后兼容：自动迁移旧格式
- ✅ 无需手动操作：首次运行自动迁移
- ✅ 性能优化：使用 set 提高查询速度

## 📊 性能影响

### 内存使用

- **旧格式**：单个大列表，随时间增长
- **新格式**：按日期分组，自动清理，内存稳定

### 查询速度

```python
# 旧方式
url in self.cache['processed_urls']  # O(n)

# 新方式（使用 set）
cached_urls = self._get_all_cached_urls()  # O(1) 查询
url in cached_urls
```

## 🎯 最佳实践

### 建议的保留天数

- **开发/测试**：7 天
- **生产环境**：30 天（默认）
- **长期归档**：90 天

### 定期维护

建议每月手动检查一次缓存：

```bash
# 查看统计
python3 scripts/cache_manager.py stats

# 清理超过60天的缓存
python3 scripts/cache_manager.py cleanup --days 60 --yes
```

### 监控缓存大小

```bash
# 查看缓存文件大小
ls -lh scripts/.rss-cache.json

# 查看 URL 总数
python3 scripts/cache_manager.py stats | grep "总 URL 数"
```

## 🐛 故障排除

### 缓存损坏

如果缓存文件损坏，可以删除后重新生成：

```bash
# 备份现有缓存
cp scripts/.rss-cache.json scripts/.rss-cache.json.backup

# 删除缓存（下次运行时会重新创建）
rm scripts/.rss-cache.json
```

### 迁移失败

如果自动迁移失败，手动检查：

```bash
# 查看缓存格式
python3 scripts/test_cache.py
```
